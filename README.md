# Mechatronics Brainbox

**An interactive 20-question multiple-choice quiz application built with
Python.**

## About the Project

Mechatronics Brainbox is a command-line quiz application created for the
**CTE213** assignment. It tests basic knowledge of mechatronics,
electronics, programming, engineering principles, and control systems.

The quiz presents 20 multiple-choice questions in a randomized order.
After each answer, the application displays whether the answer is
correct and provides a short explanation.

## Features

-   20 multiple-choice questions.
-   Randomized question order for each attempt.
-   Accepts answers using **A, B, C, or D** (case-insensitive).
-   Validates input and prompts again if an invalid option is entered.
-   Awards **5 marks** for each correct answer, for a total of **100
    marks**.
-   Displays the final score, number of correct and wrong answers, and a
    grade.
-   Shows a revision summary of incorrectly answered questions.
-   Allows the user to retake the quiz.

## Requirements

-   Python 3
-   No third-party Python packages are required. The program uses
    Python's built-in `random` module.

## How to Run

1.  Download or clone this repository.

2.  Open a terminal or command prompt in the project folder.

3.  Run the program:

    ``` bash
    python mechatronics_brainbox_ogunbayo.py
    ```

    On some systems, use:

    ``` bash
    python3 mechatronics_brainbox_ogunbayo.py
    ```

4.  Press **Enter** when prompted to start.

5.  Answer each question by entering **A**, **B**, **C**, or **D**.

6.  Review your result and choose whether to take the quiz again.

## Grading System

  Score      Grade
  ---------- -----------------------
  80--100    A - Excellent
  70--79     B - Very Good
  60--69     C - Good
  50--59     D - Pass
  Below 50   F - Needs Improvement

Each correct answer is worth 5 marks.

## Topics Covered

The questions cover introductory concepts including:

-   Mechatronics and automated systems
-   Sensors, actuators, and controllers
-   Programmable Logic Controllers (PLCs)
-   Python basics
-   Force and simple machines
-   Electrical and electronic components
-   Open-loop and closed-loop control systems
-   Robotics and Computer-Aided Design (CAD)
-   Electrical measurement instruments
